# Connector Onboarding Flow

## Пользовательский путь

### 1. Welcome Screen (3.5 сек)
**Файл**: `src/components/shared/WelcomeScreen.tsx`

- Анимированный логотип с пульсацией
- Темный фон с градиентами и парящими частицами
- Вращающееся кольцо вокруг логотипа
- Орбитальные точки
- Название бренда с градиентом
- Слоган: "Работа рядом с тобой"
- Фичи: Мгновенно, Рядом, Выгодно
- Автоматический переход к слайдам через 3.5 сек

### 2. Onboarding Slides (5 слайдов)
**Файл**: `src/components/shared/OnboardingSlides.tsx`

Каждый слайд содержит:
- Анимированную иконку с градиентом
- Заголовок
- Подзаголовок
- Описание
- Прогресс (точки внизу)
- Кнопку "Далее" / "Пропустить"

**Слайды:**
1. ⚡ **Мгновенный найм** - Работа за секунды
2. 📍 **Работа на карте** - Рядом с вами
3. 🛡️ **Безопасность** - Проверенные профили
4. 📈 **Прозрачные цены** - Без комиссий
5. 👥 **Сообщество** - Тысячи активных пользователей

На последнем слайде 2 опции:
- **"Пройти интерактивный гайд"** → Запускает тур
- **"Начать без гайда"** → Сразу к карте + модалка регистрации

### 3. Interactive Tour (опционально, 6 шагов)
**Файл**: `src/components/shared/InteractiveTour.tsx`

Анимированный оверлей с подсказками:

1. **Добро пожаловать** - Центр экрана
2. **Карта в реальном времени** - Подсветка карты
3. **Поиск** - Подсветка поисковой строки
4. **Переключение режимов** - Подсветка табов
5. **Навигация** - Подсветка нижнего меню
6. **Готово!** - Приглашение зарегистрироваться

Особенности:
- Затемненный фон (backdrop)
- Пульсирующая подсветка активного элемента
- Tooltip с описанием
- Прогресс-бар
- Кнопки "Пропустить" / "Далее" / "Начать"

### 4. Регистрация
**Файл**: `src/components/free-world/QuickRegistration.tsx`

Автоматически открывается после:
- Пропуска слайдов
- Выбора "Начать без гайда"
- Завершения интерактивного тура

## Сохранение состояния

```typescript
// sessionStorage ключи:
'connector_onboarding_complete' // true если пользователь прошел онбординг
```

При повторном визите (в рамках сессии) онбординг пропускается.

## Интеграция в главную страницу

```typescript
// src/app/page.tsx
const [onboardingPhase, setOnboardingPhase] = useState<
  'welcome' | 'slides' | 'tour' | 'complete'
>('welcome')

// Фазы:
// 1. welcome -> WelcomeScreen
// 2. slides -> OnboardingSlides
// 3. tour -> InteractiveTour (overlay)
// 4. complete -> Главная страница
```

## Анимации

Используется **Framer Motion**:
- `initial` / `animate` / `exit` для появления/исчезновения
- `AnimatePresence` для смены слайдов
- `motion.div` для пульсации и свечения
- `whileTap` / `whileHover` для интерактивности

## Фирменный стиль

**Цвета:**
- Primary: `#6B5CE7` (фиолетовый)
- Accent: `#F5BD42` (золотой)
- Success: `#34C759` (зеленый)
- Danger: `#FF3B30` (красный)

**Градиенты:**
- `from-purple-500 to-purple-700`
- `from-yellow-400 to-yellow-600`
- `from-green-500 to-green-700`
