# CONNECTOR 2.0 — АРХИТЕКТУРА ЛОГИКИ И СОСТОЯНИЙ

**Цель:** Превратить "умный прототип" → "платный продукт, в котором остаются"

**Проблема:** UI ок, но логика сломана:
- Действия без чётких концовок
- Слабое ощущение прогресса
- Пользователь не понимает "что дальше"

---

## 1. CORE FLOWS (Главные потоки)

### WORKER FLOW: Entry → Value → Payment

```
[1] ENTRY (День 0)
    │
    ├─→ Регистрация (телефон → код → имя → фото → скиллы)
    │   └─→ СОСТОЯНИЕ: profile_incomplete
    │
    ├─→ Онбординг (3 слайда макс)
    │   └─→ СОСТОЯНИЕ: onboarded
    │
    └─→ Геолокация запрошена
        └─→ СОСТОЯНИЕ: location_set / location_denied

[2] FIRST VALUE (День 0-1)
    │
    ├─→ Видит смены на карте
    │   └─→ Если 0 смен в регионе → СООБЩЕНИЕ + предложить другой город
    │
    ├─→ Первый отклик на смену
    │   └─→ СОСТОЯНИЕ: first_application_sent
    │   └─→ FEEDBACK: "Отклик отправлен! Работодатель получит уведомление"
    │
    └─→ Первое одобрение
        └─→ СОСТОЯНИЕ: first_approval
        └─→ FEEDBACK: "Поздравляем! Вас одобрили на смену [название]"
        └─→ ДЕЙСТВИЕ: Показать детали + кнопку "Начать чат"

[3] WORK VALUE (День 1-2)
    │
    ├─→ Выходит на смену
    │   └─→ СОСТОЯНИЕ: shift_in_progress
    │   └─→ UI: Таймер смены, кнопка "Завершить"
    │
    ├─→ Завершает смену
    │   └─→ СОСТОЯНИЕ: shift_completed
    │   └─→ FEEDBACK: "Смена завершена! Заработано: ₪XXX"
    │   └─→ ДЕЙСТВИЕ: Предложить оставить отзыв
    │
    └─→ Получает оплату
        └─→ СОСТОЯНИЕ: payment_received
        └─→ FEEDBACK: "₪XXX зачислено на ваш счёт"
        └─→ ПОКАЗАТЬ: Общий заработок за trial

[4] PAYMENT DECISION (День 3)
    │
    ├─→ Trial заканчивается
    │   └─→ ПОКАЗАТЬ: Итоги trial (заработок, смены, рейтинг)
    │   └─→ СООБЩЕНИЕ: "Вы заработали ₪XXX за 3 дня. Продолжить?"
    │
    ├─→ Варианты:
    │   ├─→ [Оплатить PRO] → СОСТОЯНИЕ: subscribed
    │   ├─→ [Бесплатный план] → СОСТОЯНИЕ: free_limited
    │   └─→ [Уйти] → СОСТОЯНИЕ: churned
    │
    └─→ Если не выбрал → напоминание через 24ч
```

### EMPLOYER FLOW: Entry → Value → Payment

```
[1] ENTRY (День 0)
    │
    ├─→ Регистрация (телефон → код → имя компании → сфера)
    │   └─→ СОСТОЯНИЕ: employer_profile_incomplete
    │
    └─→ Онбординг (2 слайда: как создать смену, как нанять)
        └─→ СОСТОЯНИЕ: employer_onboarded

[2] FIRST VALUE (День 0-1)
    │
    ├─→ Создаёт первую смену
    │   └─→ СОСТОЯНИЕ: first_shift_created
    │   └─→ FEEDBACK: "Смена опубликована! Ожидайте откликов"
    │   └─→ ВАЖНО: Показать превью как её видят работники
    │
    ├─→ Если 0 откликов за 2 часа
    │   └─→ УВЕДОМЛЕНИЕ: "Пока нет откликов. Попробуйте увеличить ставку или изменить время"
    │
    └─→ Получает первый отклик
        └─→ СОСТОЯНИЕ: first_applicant
        └─→ FEEDBACK: "Новый отклик от [Имя]! Рейтинг: 4.8 ⭐"
        └─→ ДЕЙСТВИЕ: Кнопки "Одобрить" / "Отклонить" / "Написать"

[3] HIRE VALUE (День 1-2)
    │
    ├─→ Одобряет кандидата
    │   └─→ СОСТОЯНИЕ: worker_approved
    │   └─→ FEEDBACK: "[Имя] одобрен! Он получил уведомление"
    │   └─→ ДЕЙСТВИЕ: Открыть чат
    │
    ├─→ Работник выходит на смену
    │   └─→ СОСТОЯНИЕ: shift_in_progress
    │   └─→ UI: Статус "На смене", время начала
    │
    └─→ Смена завершена
        └─→ СОСТОЯНИЕ: shift_completed
        └─→ FEEDBACK: "Смена завершена! Оставьте отзыв о [Имя]"
        └─→ ПОКАЗАТЬ: Сколько сэкономили vs агентство

[4] PAYMENT DECISION (День 3)
    │
    ├─→ Trial заканчивается
    │   └─→ ПОКАЗАТЬ: Итоги (сколько нанял, сколько потратил, vs агентство)
    │   └─→ СООБЩЕНИЕ: "Вы сэкономили ₪XXX по сравнению с агентством"
    │
    └─→ Варианты:
        ├─→ [Оплатить PRO] → безлимитные смены
        ├─→ [Бесплатный план] → 1 смена/месяц
        └─→ [Уйти]
```

## 2. STATE SYSTEM (Система состояний)

| State | Что видит | Что может | Что блокирует |
|-------|-----------|-----------|---------------|

## 3. ACTION → RESULT MAP

### Worker Actions

| Действие | Немедленный feedback | Новое состояние | Следующее действие |
|----------|---------------------|-----------------|-------------------|
| Ввёл телефон | Spinner → "Код отправлен на XXX-XXX" | `code_sent` | Ввести код |
| Ввёл код | ✓ анимация → "Добро пожаловать!" | `authenticated` | Заполнить профиль |
| Сохранил профиль | ✓ "Профиль сохранён" | `profile_complete` | Искать работу |
| Откликнулся на смену | ✓ "Отклик отправлен!" + confetti | `application_pending` | Ждать ответа |
| Получил одобрение | 🎉 Push + modal "Вас одобрили!" | `application_approved` | Открыть чат |
| Написал в чат | ✓ галочка отправки | — | Ждать ответа |
| Начал смену | ▶️ Таймер запущен | `shift_in_progress` | Работать |
| Завершил смену | 🎉 "Заработано ₪XXX!" | `shift_completed` | Оставить отзыв |
| Оставил отзыв | ✓ "Спасибо за отзыв!" | — | Искать новую работу |
| Оплатил подписку | 🎉 "Добро пожаловать в PRO!" | `subscribed` | Пользоваться |

### Employer Actions

| Действие | Немедленный feedback | Новое состояние | Следующее действие |
|----------|---------------------|-----------------|-------------------|
| Создал смену | ✓ "Смена опубликована!" + превью | `shift_published` | Ждать откликов |
| Одобрил кандидата | ✓ "[Имя] одобрен и уведомлён" | `worker_approved` | Написать в чат |
| Отклонил кандидата | ✓ "Отклонено" (мягко) | `worker_rejected` | Смотреть других |
| Отменил смену | ⚠️ "Смена отменена. Работники уведомлены" | `shift_cancelled` | Создать новую? |
| Завершил смену | ✓ "Смена завершена!" | `shift_completed` | Оставить отзыв |
| Оплатил | 🎉 "PRO активирован!" | `subscribed` | Создавать смены |

### Негативные сценарии (КРИТИЧНО!)

| Ситуация | Что происходит сейчас | Что ДОЛЖНО быть |
|----------|----------------------|-----------------|
| Работник не пришёл | Ничего | Employer: кнопка "Неявка" → dispute flow |
| Employer отменил за 1ч | Ничего | Worker: уведомление + компенсация? |
| SMS не пришёл | Ничего | Кнопка "Не пришёл код" → альтернативы |
| Отклик без ответа 24ч | Ничего | Auto-reminder employer |
| Смена не опубликовалась | Ничего | Retry + error message |
| Trial закончился | Ничего | Paywall + итоги |

## 4. TRIAL → PAYMENT LOGIC

### День 1: "Покажи ценность"

```
УТРО:
- Welcome modal: "У вас 3 дня PRO-доступа!"
- Показать: что включено в PRO (список)
- CTA: "Начать поиск" (не "Оплатить")

ДЕНЬ:
- Первый отклик → celebration
- Первое одобрение → bigger celebration
- Progress bar: "1 из 3 дней | 1 смена найдена"

ВЕЧЕР:
- Push: "Итоги дня: X откликов, X просмотров профиля"
- НЕ упоминать оплату
```

### День 2: "Закрепи привычку"

```
УТРО:
- Push: "Новые смены рядом с вами!"
- Badge: "Осталось 2 дня PRO"

ДЕНЬ:
- Показывать прогресс: "Заработано за trial: ₪XXX"
- Если работал: "Отлично! Ещё X смен доступно"
- Если не работал: "Вы пропускаете возможности! Вот смены рядом..."

ВЕЧЕР:
- Мягкое упоминание: "Завтра последний день PRO"
- НЕ давить на оплату
```

### День 3: "Реши"

```
УТРО:
- Modal: "Последний день PRO!"
- Показать ВСЕ итоги:
  - Заработано: ₪XXX
  - Смен выполнено: X
  - Рейтинг: X.X
  - Просмотров профиля: X
- CTA: "Продолжить с PRO" / "Выбрать план"

ДЕНЬ:
- Countdown badge: "PRO: осталось X часов"
- Показывать что будет недоступно:
  "После trial: только 2 отклика в день"

ВЕЧЕР (за 3 часа до конца):
- Full-screen modal (но dismissable):
  "Trial заканчивается"

  [ИТОГИ ВИЗУАЛЬНО]

  ┌─────────────────────────────────┐
  │  PRO ₪29/мес                    │
  │  ✓ Безлимитные отклики          │
  │  ✓ Приоритет в поиске           │
  │  ✓ Статистика                   │
  │  [ВЫБРАТЬ PRO]                  │
  └─────────────────────────────────┘

  ┌─────────────────────────────────┐
  │  FREE                           │
  │  • 2 отклика в день             │
  │  • Базовый профиль              │
  │  [ОСТАТЬСЯ НА FREE]             │
  └─────────────────────────────────┘

ПОСЛЕ ОКОНЧАНИЯ:
- Soft paywall при попытке использовать PRO-фичи
- НЕ полная блокировка
- Reminder через 3 дня: "Скучаем! Вот что вы пропустили..."
```

### Почему оплата будет логичной:

1. **Заработал → хочет ещё** (worker видит реальные деньги)
2. **Сэкономил → хочет ещё** (employer видит сравнение с агентством)
3. **Привык → не хочет терять** (3 дня достаточно для привычки)
4. **Понял ценность → готов платить** (не "купи кота в мешке")

## РЕЗЮМЕ

**Главная проблема:** Пользователь не понимает "что произошло" и "что дальше"

**Решение:**
1. Каждое действие → чёткий feedback
2. Каждое состояние → видимый статус
3. Каждый день trial → ощутимая ценность
4. Окончание trial → логичный выбор (не forced)

**Порядок работы:**
1. Phase 1 (блокеры) — делаем ПЕРВЫМИ
2. Phase 2 (retention) — после Phase 1
3. Phase 3 (nice-to-have) — если есть время
