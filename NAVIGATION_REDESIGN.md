# Navigation Redesign - Connector App

## Дата: 2024-01-21
## Версия: 2.1

---

## Проблема

Предыдущая навигация имела 4 кнопки в нижней панели:
- 🗺️ Free World
- 💼 Worker (режим работника)
- 🏢 Employer (режим работодателя)
- 👤 Profile

**Отзыв пользователя**: "У нас очень много нелогичных некликабельных кнопок. Режимы работника или работодателя надо убрать снизу - они путают глаза. Нужно сделать отдельной менюшкой, как-нибудь аккуратно."

---

## Решение

### 1. Упрощённая нижняя навигация (4 основные функции)

**Новые элементы**:
- 🗺️ **Explore** (Free World Map) - главная карта
- 🔍 **Search** - поиск работников и задач
- 🔔 **Notifications** - уведомления (с бейджем)
- 👤 **Profile** - профиль пользователя

**Преимущества**:
- Интуитивно понятные иконки
- Универсальные функции для всех режимов
- Меньше визуального шума
- Стандартная навигационная схема (как в Instagram, WhatsApp)

---

### 2. Элегантный Mode Selector

**Расположение**: Страница профиля → Раздел "Режим работы"

**Компонент**: `ModeSelector.tsx`
- Красивая карточка с текущим режимом
- Иконка с градиентом
- Название и описание
- Клик открывает полноэкранное модальное окно

**Модальное окно для выбора режима**:
```
┌────────────────────────────────┐
│  Выберите режим                │
│  Переключайтесь между режимами │
├────────────────────────────────┤
│  🌍 Свободный мир         ✓    │
│  Изучайте карту...             │
├────────────────────────────────┤
│  💼 Режим работника            │
│  Ищите работу...               │
├────────────────────────────────┤
│  🏢 Режим работодателя         │
│  Создавайте задачи...          │
└────────────────────────────────┘
```

**Особенности дизайна**:
- Backdrop blur эффект
- Spring анимация появления
- Чекмарк на выбранном режиме
- Градиенты для каждого режима:
  - Free World: `from-blue-500 to-cyan-500`
  - Worker: `from-purple-500 to-pink-500`
  - Employer: `from-amber-500 to-orange-500`

## Как пользоваться

### Для пользователя:

1. **Открыть профиль** (нижняя панель → иконка Profile)
2. **Найти секцию "Режим работы"** (после "Навыки")
3. **Кликнуть на карточку с текущим режимом**
4. **Выбрать нужный режим из списка**
5. **Приложение автоматически перенаправит на соответствующую страницу**

### Для разработчика:

```typescript
import { ModeSelector } from '@/components/shared'

// Использование:
<ModeSelector onModeChange={(mode) => console.log('Selected:', mode)} />

// Store автоматически обновится:
const { user, setMode } = useConnectorStore()
console.log(user.mode) // 'free-world' | 'worker' | 'employer'
```
