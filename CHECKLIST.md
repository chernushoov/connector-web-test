# ✅ Checklist - Connector App

## Проверьте что всё работает:

### 1. Onboarding Flow
- [ ] Откройте http://localhost:3000 в режиме инкогнито
- [ ] Видите Welcome Screen с анимированным логотипом
- [ ] Кнопка "Продолжить" появляется через 2-3 секунды
- [ ] Нажмите "Продолжить" → показываются 5 слайдов
- [ ] На последнем слайде есть 2 кнопки: "Гайд" и "Начать без гайда"
- [ ] Выберите "Начать без гайда" → переход на главную страницу

### 2. Навигация (нижняя панель)
- [ ] Видите 4 кнопки: Explore, Search, Notifications, Profile
- [ ] Кнопки Worker и Employer ОТСУТСТВУЮТ ✓
- [ ] Нажмите на каждую кнопку → страницы переключаются
- [ ] Активная кнопка подсвечивается фиолетовым

### 3. ModeSelector (в профиле)
- [ ] Откройте http://localhost:3000/profile
- [ ] Прокрутите вниз до секции "Режим работы"
- [ ] Видите карточку с текущим режимом и иконкой
- [ ] Нажмите на карточку → открывается модальное окно
- [ ] Видите 3 режима с градиентами и описаниями
- [ ] Выберите другой режим → происходит переход на соответствующую страницу

### 4. Основные страницы
- [ ] http://localhost:3000 - главная с картой
- [ ] http://localhost:3000/profile - профиль
- [ ] http://localhost:3000/worker - worker dashboard
- [ ] http://localhost:3000/employer - employer dashboard
- [ ] http://localhost:3000/search - поиск
- [ ] http://localhost:3000/notifications - уведомления

### 5. Сброс onboarding (для повторного тестирования)
- [ ] Откройте консоль (F12)
- [ ] Выполните: `sessionStorage.removeItem('connector_onboarding_complete')`
- [ ] Обновите страницу (F5)
- [ ] Onboarding появляется снова ✓

---

## Если что-то не работает:

1. Убедитесь что dev сервер запущен: `npm run dev`
2. Проверьте консоль браузера (F12) на ошибки
3. Попробуйте очистить кеш браузера (Ctrl+Shift+R)
4. Откройте в режиме инкогнито
